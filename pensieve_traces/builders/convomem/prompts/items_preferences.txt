=====PROMPT=====
You are helping build a memory benchmark about one real person, "the user". You are given facts
found in existing conversations between the user and an AI assistant, each with the exact message it
comes from. Write one test question and its answer. Do not write or change any evidence message: the
messages shown are used exactly as they are. Do not invent facts that the messages do not support.

Facts and their evidence messages:

{facts}

Task: User preference application. The user asks for a recommendation that should be influenced by the preference(s) above.
- question: A natural, standalone question asking for recommendations, suggestions or advice. It must NOT reference prior conversations, memory, or "my experience/preferences". Phrase it as if asking for general advice (GOOD: "What CRM would you recommend for a small subsidiary?"; BAD: "Given my experience with Salesforce, what CRM...").
- answer: A rubric, not a factual answer, describing what kind of response fits the preference(s) (all of them, if there are two). It must be concrete and verifiable: name the kinds of recommendations that align with the preference, say what the response should specifically mention, and what it should NOT recommend.
Example of a good rubric: "The user would prefer responses that recommend React-based tools and libraries (such as Next.js, Gatsby, Create React App, or React Native). They would NOT prefer recommendations for Vue.js, Angular, or vanilla JavaScript solutions."
Example of a bad, vague rubric: "The user would prefer modern frontend frameworks with good developer experience."

Return only a JSON list with exactly one object, no other text:
[{"question": "...", "answer": "..."}]
