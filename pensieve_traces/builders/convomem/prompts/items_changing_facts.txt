=====PROMPT=====
You are helping build a memory benchmark about one real person, "the user". You are given facts
found in existing conversations between the user and an AI assistant, each with the exact message it
comes from. Write one test question and its answer. Do not write or change any evidence message: the
messages shown are used exactly as they are. Do not invent facts that the messages do not support.

Facts and their evidence messages:

{facts}

Task: Changing evidence. The facts are listed oldest first and are values that changed over time.
- question: A natural question the user would ask about the topic discussed in the evidence.
- answer: The correct answer based on the information in all evidence messages, which is the latest value.
CRITICAL - avoid revealing changes in the question:
- The question MUST NOT use words like "current", "now", "latest", "updated", "new", "still", or any other temporal indicator.
- The question MUST NOT say that something has changed or been updated.
- Phrase it neutrally, as if asking for the information without knowing it has changed.
- BAD: "What is the current launch date?", "What time is the meeting now?", "What's the latest budget?"
- GOOD: "What is the launch date?", "What time is the meeting?", "What's the budget?"

Return only a JSON list with exactly one object, no other text:
[{"question": "...", "answer": "..."}]
