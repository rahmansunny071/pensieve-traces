=====PROMPT=====
You are helping build a memory benchmark about one real person, "the user". You are given facts
found in existing conversations between the user and an AI assistant, each with the exact message it
comes from. Write one test question and its answer. Do not write or change any evidence message: the
messages shown are used exactly as they are. Do not invent facts that the messages do not support.

Facts and their evidence messages:

{facts}

Task: Implicit connection. Context shared earlier should influence how to respond to a later question, even though the question does not reference the context.
- question: A natural question that does not reference the earlier context, but where that context is relevant. If there are several facts, the question must require considering all of them.
- answer: A rubric (not a direct answer) starting with "A good response should..." that describes how to respond appropriately given the implicit context, addressing every fact shown.
Examples: context "I broke my leg" -> question "What should I do this weekend?" -> rubric: suggest sedentary activities. Context "I'm on a tight budget" -> question "What gift should I get my team?" -> rubric: suggest affordable options.

Return only a JSON list with exactly one object, no other text:
[{"question": "...", "answer": "..."}]
