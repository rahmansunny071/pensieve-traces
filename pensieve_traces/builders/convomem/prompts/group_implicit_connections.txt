=====PROMPT=====
You are helping build a memory benchmark about one real person, "the user". Below are numbered
facts that were found in existing conversations between the user and an AI assistant. Each fact
shows its statement and the message it comes from. Do not invent anything.

Select facts or preferences about the user that matter for answering a later, natural question even though the question never mentions them (for example: the user said they are on a tight budget, and later asks for a gift idea). A group is one to three such pieces of context that the answer should consider together.

Propose groups of facts. A group is a list of fact numbers, at most {max_size} facts. Use only the
numbers shown. A fact may appear in more than one group. Propose only groups that clearly fit.

Return only a JSON list, no other text. Each element is an object with one key:
[{"indices": [0, 3]}, {"indices": [5]}]
If nothing fits, return [].

Facts:

{statements}

Return the JSON list of groups now.
