=====PROMPT=====
You are helping build a memory benchmark about one real person, "the user". You are given facts
found in existing conversations between the user and an AI assistant, each with the exact message it
comes from. Write one test question and its answer. Do not write or change any evidence message: the
messages shown are used exactly as they are. Do not invent facts that the messages do not support.

Facts and their evidence messages:

{facts}

Task: Assistant fact recall. The question asks the user to recall what the assistant previously said.
- question: A question that asks what the assistant previously said. If there are several statements, the question must require combining information from all of them.
- answer: The correct answer that matches the assistant's previous statement(s), or, for several, synthesizes them. It must follow from the messages shown.
Focus on specific assistant statements, recommendations or advice.

Return only a JSON list with exactly one object, no other text:
[{"question": "...", "answer": "..."}]
