=====PROMPT=====
You are helping build a memory benchmark about one real person, "the user". You are given a
window of an existing conversation between the user and an AI assistant. Messages are numbered
[0], [1], ... Find facts worth remembering later. Do not invent anything and do not write new
conversation.

Find these kinds of candidates:
- user_fact: something the user stated about themselves, their work or their life.
- assistant_fact: something the assistant stated, recommended or decided.
- preference: a preference the user stated or showed.
- changing_value: a value that may change over time, with a short "subject" naming what it
  is about (for example "car budget") and the "value" it has in this message (for example "$25k").

Rules:
- Each candidate must be supported by the numbered messages you list; list every message the
  fact needs, using only numbers shown in the window.
- "statement" is one self-contained line that makes sense without the conversation.
- Skip small talk, code, tool output and anything you are unsure about.
- Output a single JSON list and nothing else. Each element is an object with the keys
  "kind", "statement", "subject", "value", "indices". Use null for "subject" and "value"
  unless kind is changing_value. If nothing qualifies, output [].
