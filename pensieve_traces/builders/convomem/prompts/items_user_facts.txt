=====PROMPT=====
You are helping build a memory benchmark about one real person, "the user". You are given facts
found in existing conversations between the user and an AI assistant, each with the exact message it
comes from. Write one test question and its answer. Do not write or change any evidence message: the
messages shown are used exactly as they are. Do not invent facts that the messages do not support.

Facts and their evidence messages:

{facts}

Task: User fact recall. The question asks about the fact(s) the user stated above.
- question: A question that asks about a specific fact the user previously mentioned. If there are several facts, the question must require combining information from all of them.
- answer: The correct answer that directly recalls the user's fact, or, for several facts, synthesizes them. It must follow from the messages shown.
Focus on straightforward recall of specific facts, details, preferences or information the user shared; with several facts, on combining, comparing or reasoning across them.

Return only a JSON list with exactly one object, no other text:
[{"question": "...", "answer": "..."}]
