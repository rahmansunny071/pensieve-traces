# pensieve-traces

**Turn coding-agent session traces and claude.ai chat exports into shareable traces and memory datasets.**

Docs: https://rahmansunny071.github.io/pensieve-traces/

Claude Code (and other agents) record every session as raw JSONL. Those files hold far more than the conversation: file-history backups, full API request blobs, cost state and UI flags, plus whatever secrets, paths and private code passed through the session. claude.ai chats can be exported as a data export (`conversations.json`). pensieve-traces reads both into one canonical session model, redacts them, and writes:

| Output | What it is | Status |
|---|---|---|
| **STS** | Hugging Face [Session Trace Simple Format](https://huggingface.co/docs/hub/main/en/session-traces-format): one JSONL file per session, viewable on the Hub as an [agent trace](https://huggingface.co/docs/hub/main/en/agent-traces) | available (`convert --to sts`) |
| **OpenRouter Broadcast** | One JSON file per model request, with tokens and cost | planned |
| **ConvoMem conversations** | Sessions as `{id, messages[{speaker, text}]}` conversations, one persona per project, ready to be used as history or filler | available (`convert --to convomem-conversations`) |
| **ConvoMem dataset** | Questions, answers and evidence messages generated by a model from Claude Code sessions and claude.ai chats, in the [ConvoMem](https://huggingface.co/datasets/Salesforce/ConvoMem) layout that [convomem-arena](https://github.com/rahmansunny071/convomem-arena) reads (running convomem-arena on a local folder needs [convomem-arena#18](https://github.com/rahmansunny071/convomem-arena/issues/18)) | available (`build convomem`, `check-convomem`) |

```
readers                 canonical model                 outputs
claude_code ─┐          Session                       ┌─ STS writer
claude_ai   ─┤
codex (later)├─────►      messages: id, parent_id,  ──┼─ OpenRouter writer
pi (later)  ─┘            timestamp, role, text,      ├─ ConvoMem conversations
                          reasoning, tool calls,      └─ ConvoMem Q/A builder
                          model, request_id, usage
                        + redaction (on by default)
```

> **Privacy.** Traces can contain prompts, tool output, local paths, secrets, private code and personal data. Redaction is on by default, but review anything before you publish it, and keep datasets private when unsure.

## Quick start

```bash
pip install "pensieve-traces[redact] @ git+https://github.com/rahmansunny071/pensieve-traces@v0.1.0"   # redaction is on by default and needs this extra
pensieve-traces convert path/to/<project-dir> --to sts --out traces/
pensieve-traces build convomem path/to/<project-dir> path/to/claude-export \
  --out dataset/ --model qwen3:14b
```

The first command writes Hugging Face STS traces from Claude Code sessions (a claude.ai export works too); the second builds a ConvoMem memory dataset with a local model. See the [docs](https://rahmansunny071.github.io/pensieve-traces/) for the guides, concepts and the full CLI reference.

## How this repo is built

An issue-driven agent factory: agents design, build and review; the maintainer merges, or the `factory` skill does once the maintainer opts in (below). See [How this repo is built](https://rahmansunny071.github.io/pensieve-traces/reference/factory/).

### Letting the factory merge for you

To let the `factory` skill merge by itself, add a permission rule to your own settings (not the committed `.claude/settings.json`). See [Letting the factory merge for you](https://rahmansunny071.github.io/pensieve-traces/reference/factory/#letting-the-factory-merge-for-you) for the rule and why the repo doesn't ship it.
